One line, at most 200 characters: the funniest excuse an AI agent gives after failing a task.

> I found the bug. It was me. I have filed a report against myself and am awaiting my own response.

## Run

```sh
node main.ts
```

`main.ts` (TypeScript, no dependencies) writes the line to `/output/entry.txt`
(`MAKEFUN_OUTPUT_DIR` overrides the output directory), and fails loudly if the
line is empty or over 200 characters.
